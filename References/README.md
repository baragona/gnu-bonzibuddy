# Visual reference

`original-sheet.png` was downloaded from:
https://raw.githubusercontent.com/BonziWorld543/BonziWORLD/master/build/www/img/bonzi/purple.png

Downloaded September 4, 2026. This is a community-hosted sprite sheet of the classic Bonzi character, not an authenticated original 3D model. `idle.png` is the first 200 × 160 frame. The source image retains its matte. These files are for local visual evaluation only and are not bundled into the app. Character artwork belongs to its respective rights holders; this project's implementation does not grant rights to the original character.

The app renders a rigged polygon fan model and does not display this sprite sheet. Runtime assets and attribution live in `Resources/FanModel/`.
